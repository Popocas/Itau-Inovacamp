PROTÓTIPO — ASSISTENTE FINANCEIRO

Arquivos:
- index.html
- style.css
- script.js

Como abrir:
1. Extraia o .zip.
2. Abra index.html no navegador.
3. Para recursos de voz/microfone funcionarem melhor, use Chrome/Edge e permita acesso ao microfone.
4. Em alguns navegadores, a Web Speech API pode exigir que o site seja servido por http/https. Se necessário, rode um servidor local simples:
   python -m http.server 8000
   e abra http://localhost:8000

Observações:
- Não há backend.
- Não há integração com IA externa.
- Todos os dados são fictícios.
- Nenhuma transação financeira real é realizada.
- O protótipo não é um produto oficial do Itaú.
